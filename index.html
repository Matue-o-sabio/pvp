Painel de Diagnóstico de Conexão

Por que o servidor Python no localhost falha no GitHub Pages?

1. Conteúdo Misto HTTPS

O GitHub Pages roda em HTTPS://. Navegadores por segurança bloqueiam chamadas para servidores inseguros em HTTP://localhost.

2. Regras de CORS

Se o servidor Python não enviar os cabeçalhos Access-Control-Allow-Origin: *, o navegador recusa a conexão via Socket.IO.

3. Solução com Ngrok

Execute ngrok http 5000 na sua máquina. O Ngrok gera uma URL HTTPS segura aceita pelo GitHub Pages!

Código do Servidor Python Corrigido

Flask + Socket.IO com suporte a CORS e suporte ao GitHub Pages

  1. Instale as dependências no terminal: pip install flask flask-cors flask-socketio eventlet
  2. Salve o código abaixo como server.py e execute: python server.py
  3. Abra outro terminal e gere a URL HTTPS com Ngrok: ngrok http 5000
  4. Cole a URL HTTPS gerada no menu do jogo no campo "URL do Servidor Python".
import eventlet
eventlet.monkey_patch()

from flask import Flask, request
from flask_cors import CORS
from flask_socketio import SocketIO, emit, join_room, leave_room

app = Flask(__name__)
# Permite CORS para qualquer origem (incluindo GitHub Pages)
CORS(app, resources={r"/*": {"origins": "*"}})

socketio = SocketIO(app, cors_allowed_origins="*", async_mode='eventlet')

rooms = {}

@app.route('/')
def index():
    return {"status": "Servidor CineQuote Online!", "cors": "enabled"}

@socketio.on('create_room')
def handle_create_room(data):
    room = data.get('room')
    player = data.get('player')
    join_room(room)
    rooms[room] = {'host': request.sid, 'players': [player]}
    emit('room_created', {'room': room, 'players': rooms[room]['players']}, to=room)

@socketio.on('join_room')
def handle_join_room(data):
    room = data.get('room')
    player = data.get('player')
    if room in rooms:
        join_room(room)
        rooms[room]['players'].append(player)
        emit('player_joined', {'player': player, 'players': rooms[room]['players']}, to=room)
    else:
        emit('error', {'message': 'Sala não encontrada'})

@socketio.on('send_chat')
def handle_chat(data):
    emit('chat_message', data, to=data.get('room'))

@socketio.on('submit_guess')
def handle_guess(data):
    emit('guess_result', data, to=data.get('room'))

if __name__ == '__main__':
    print("🚀 Servidor CineQuote rodando na porta 5000...")
    socketio.run(app, host='0.0.0.0', port=5000, debug=True)
