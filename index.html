Código pronto para rodar com Flask-SocketIO

Se preferir hospedar seu próprio servidor websocket em Python usando o VS Code em vez do Firebase, instale as dependências e rode o script abaixo:

# server.py - Servidor WebSocket para CineQuote Showdown
from flask import Flask, render_template
from flask_socketio import SocketIO, emit, join_room, leave_room
import random, string

app = Flask(__name__)
app.config['SECRET_KEY'] = 'cinequote_secret_key'
socketio = SocketIO(app, cors_allowed_origins="*")

rooms = {} # Guarda o estado das salas

@socketio.on('create_room')
def handle_create_room(data):
    room_code = ''.join(random.choices(string.ascii_uppercase + string.digits, k=5))
    rooms[room_code] = {
        'host': data['username'],
        'players': {request.sid: {'name': data['username'], 'score': 0, 'ready': True}},
        'settings': data.get('settings', {'roundTime': 25, 'maxRounds': 8})
    }
    join_room(room_code)
    emit('room_created', {'roomCode': room_code, 'room': rooms[room_code]}, room=room_code)

@socketio.on('join_room')
def handle_join_room(data):
    code = data['roomCode'].upper()
    if code in rooms:
        join_room(code)
        rooms[code]['players'][request.sid] = {'name': data['username'], 'score': 0, 'ready': False}
        emit('player_joined', {'players': rooms[code]['players']}, room=code)
    else:
        emit('error', {'message': 'Sala não encontrada!'})

@socketio.on('send_chat')
def handle_chat(data):
    emit('new_chat', {'user': data['username'], 'msg': data['message']}, room=data['roomCode'])

if __name__ == '__main__':
    print("🎬 Servidor CineQuote rodando em http://localhost:5000")
    socketio.run(app, host='0.0.0.0', port=5000, debug=True)

Como Publicar no GitHub Pages

Coloque seu jogo online de graça em 3 minutos

  1. Crie uma conta gratuita em github.com caso não tenha.
  2. Crie um novo repositório público chamado meu-jogo-cinema.
  3. Faça o upload deste arquivo nomeando-o exatamente como index.html no repositório.
  4. Vá nas configurações do repositório (**Settings** -> **Pages**).
  5. Em **Branch**, selecione main (ou `master`) e clique em **Save**.
  6. Aguarde 1 minuto e seu site estará online no link fornecido pelo GitHub! (ex: `https://seu-usuario.github.io/meu-jogo-cinema`).
